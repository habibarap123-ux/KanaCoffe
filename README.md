# Kana Coffee ☕
Always in Heart

Web menu dan kasir untuk rider Kana Coffee (ice coffee sepeda listrik keliling).

## Fitur
- Menu dengan foto dan harga, termasuk sisa stok
- Kasir: tunai (hitung kembalian), QRIS, dan bon
- Stok awal, tambah dari produksi, dan oper antar rider
- Laporan harian karyawan, bisa disalin ke WhatsApp
- Mode Rider lewat ikon 🛵 di pojok atas

Dibuat oleh Abibb.
